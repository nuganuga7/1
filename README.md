# 11월 제철 과일

업로드한 홈페이지 시안을 기반으로 제작한 반응형 정적 홈페이지입니다.

- PC 4열, 태블릿·모바일 2열, 작은 화면 1열
- 상품 선택 시 상세 정보 표시
- 원본 사진과 표시 가격 보존
- 주문·결제는 연결되어 있지 않습니다.

## 배포

저장소 Settings → Pages → Deploy from a branch → main / (root) → Save.

## 구성

- index.html: 페이지 구조, 디자인, 상품 정보 및 상세 팝업
- assets/reference.png: 제공받은 원본 이미지
- .nojekyll: 정적 파일 배포 설정

이미지에 포함된 가격은 제공된 시안 기준입니다. 실제 판매 시 상품·가격 및 주문 링크를 확인하고 수정하세요.
