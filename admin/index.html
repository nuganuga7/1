GitHub 계정으로 관리하기

아래 버튼으로 Pages CMS에 접속한 뒤 nuganuga7 계정으로 로그인하세요. 실제 편집은 저장소의 수정 권한이 있는 계정만 가능합니다.

GitHub로 관리자 로그인 →

이 페이지는 로그인 안내입니다. 로그인과 편집은 Pages CMS에서 진행됩니다. 홈페이지에는 비밀번호나 인증 토큰을 저장하지 않습니다.

처음 한 번만 연결해 주세요

  1. Pages CMS에서 Sign in with GitHub를 선택합니다.
  2. GitHub 연결 승인 화면에서 대상 저장소를 선택할 수 있으면 Only select repositories → nuganuga7/1만 선택합니다.
  3. 관리할 저장소 1, 브랜치 main을 엽니다. 관리 항목은 이미 준비되어 있습니다.
  4. 상품 관리 또는 홈페이지 · 타임세일 설정을 열어 수정하고 Save를 누릅니다.

저장 후 GitHub의 배포가 완료되면 홈페이지에 반영됩니다. 바로 보이지 않으면 잠시 후 새로고침하세요.
